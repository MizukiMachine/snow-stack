# voxel-tetris

Three.js と TypeScript で作る 3D テトリス試作です。

現状は以下まで実装済みです。

- 3D フィールド描画
- テトロミノの生成
- 移動と 3 軸回転
- 自動落下
- 着地時の固定
- 次ピース生成
- ゲームオーバー
- `Y` 層が全面埋まったときのレイヤー消去
- 簡易スコア / レベル
- 壁キック付き回転
- `Space` によるハードドロップ

## セットアップ

```bash
npm install
npm run dev
```

## 操作

- `ArrowLeft` / `ArrowRight`: X 軸方向の移動
- `ArrowUp` / `ArrowDown`: Z 軸方向の移動
- `W`: Y 軸上方向の移動
- `S`: Y 軸下方向の移動（ソフトドロップ）
- `Q` / `E`: Y 軸回転
- `A` / `D`: Z 軸回転
- `Z` / `X`: X 軸回転
- `Space`: ハードドロップ
- `C`: ホールド
- `P` / `Escape`: ポーズ
- `R`: リスタート

## 現状の仕様メモ

- 消去判定は `Y` 層単位です。
- 回転時は簡易的な壁キックを行います。
- スコアとレベルは簡易実装です。
- 効果音は未実装です。
- テストコードはまだありません。
