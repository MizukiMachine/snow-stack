# voxel-tetris

Three.js と TypeScript で作る 3D テトリス試作です。

現状は以下まで実装済みです。

- 3D フィールド描画
- テトロミノの生成
- 移動と 3 軸回転
- 自動落下
- 着地時の固定
- 次ピース生成
- ゲームオーバー
- `Y` 層が全面埋まったときのレイヤー消去

## セットアップ

```bash
npm install
npm run dev
```

## 操作

- `ArrowLeft` / `ArrowRight`: 左右移動
- `ArrowUp` / `ArrowDown`: 前後移動
- `W`: 上移動
- `S`: 下移動
- `Q` / `E`: Y 軸回転
- `A` / `D`: Z 軸回転
- `Z` / `X`: X 軸回転
- `R`: リスタート
